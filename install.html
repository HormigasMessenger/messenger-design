What it is

A Progressive Web App

There is nothing to download from a store and no account beyond the one you already sign in with. The messenger is a PWA: a website your browser can promote to a real app. Once installed it lives on your home screen or dock, launches in its own window, keeps working when the network drops, and delivers push notifications. Below is the one small gesture each platform needs.

Install it

Pick your device

iPhone & iPad — Safari

  1. Open the app in Safari.
  2. Tap the Share button ↑.
  3. Choose Add to Home Screen, then Add.

iOS installs PWAs only from Safari, not Chrome.

Android — Chrome

  1. Open the app in Chrome.
  2. Tap the ⋮ menu (top right).
  3. Choose Install app (or Add to Home screen).

Chrome may also show an “Install” banner on its own.

Desktop — Chrome / Edge

  1. Open the app in Chrome or Edge.
  2. Click the install icon at the right of the address bar…
  3. …or ⋮ menu → Install Hormigas Messenger.

Safari on macOS: File → Add to Dock.

Already inside the app

  1. Open ℹ️ App info (top of the chat list).
  2. Find the Install app section.
  3. Tap Install — a one-tap button where the browser supports it.

Falls back to these same steps where it can’t.

Good to know

After it’s installed

It updates itself — the next launch quietly picks up the latest version, no reinstall. It runs offline for what you’ve already loaded, and re-syncs when you’re back. Remove it like any app: long-press the icon → Remove, or the browser’s app settings.

The same ℹ️ App info dialog also holds “Erase everything on this device” — a one-gesture wipe of all local data (the device key, secret messages, cached chats and files) for when you need to hand the device on clean. A fresh key is created the next time you sign in.
